# WMS-INSPIRA-AREAS-ASIGNADAS
Áreas Asignadas (v2.5.0) es un panel que se inserta con el shortcode [areas_asignadas] y solo lo ve el rol empresa_admin. En él, el administrador de una empresa ve sus áreas con cupos, estado y fecha de expiración, y entra a los usuarios de cada área para revisar su test, su perfil y su avance en LearnDash.
